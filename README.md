# Авто Сфера · Управленка

Дашборд управленческой отчётности: тело инвесторов (план/факт), сделки с техникой, доходы и выплаты инвесторам, р/с и долги, результат по месяцам и по менеджерам. Данные вносят несколько человек одновременно, всё синхронизируется через Firebase.

Пока в `config.js` стоит `null`, страница работает в демо-режиме с вымышленными данными.

## Файлы
- `index.html`, `style.css`, `app.js` — сама страница.
- `config.js` — настройки Firebase (не секретные).
- `database.rules.json` — правила доступа к базе: читать могут только люди из списка `members`, менять — только с ролью `edit`.

## Настройка (один раз)
1. **Firebase.** console.firebase.google.com → «Создать проект» (например, `avtosfera`), Google Analytics можно выключить.
2. **Вход.** Build → Authentication → Начать → Sign-in method → Email/Password → включить. На вкладке Users добавить каждого пользователя (почта + пароль).
3. **База.** Build → Realtime Database → Создать базу (регион Europe) → режим «locked». Вкладка Rules → вставить содержимое `database.rules.json` → Publish.
4. **Список доступа.** Realtime Database → Data → добавить узел `members`, в нём для каждого человека ключ = почта, где точки заменены на запятые (`ivan@mail,ru`), значение: `name` (имя) и `role` (`edit` — может менять, `view` — только смотреть).
5. **Ключи.** Настройки проекта (шестерёнка) → «Ваши приложения» → Web `</>` → зарегистрировать → скопировать объект `firebaseConfig` в `config.js` вместо `null`.
6. **Authentication → Settings → Authorized domains** → добавить `e6082872-ship-it.github.io`.
7. **GitHub Pages.** Репозиторий → Settings → Pages → Source: Deploy from a branch → `main` / root → Save. Через минуту сайт откроется по адресу `https://e6082872-ship-it.github.io/avtosfera/`.
8. Войти редактором → ⚙ Настройки → «Загрузка из Excel» → выбрать «АСИнвестиции». Загрузятся все сделки, уже выплаченное инвесторам и остаток р/с.

## Как считается
- Маржа = продажа − покупка − расходы − бонус менеджера.
- НДС = (продажа − покупка) × 22/122.
- Прибыль = маржа − НДС. Доход инвесторов = 50% прибыли (убыточная сделка даёт 0), делится по вкладам: Ростов 6 млн, Толик 3 млн.
- Факт тела = р/с + вложено в технику и брони + нам должны − мы должны − к выплате инвесторам. План тела = сумма вкладов (9 млн).
- У сделки можно вручную задать прибыль или доход инвестора, если формула не подходит.
